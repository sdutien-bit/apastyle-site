# APA Style Knowledge Study — website prototype

Static website, 7 pages, HTML + CSS + JavaScript, no external libraries.

Open `index.html` in any browser.

Pages: index, study, apa-guide, quiz, instruments, results, contact.

## Adding the real results
Open `js/results-data.js` and replace each `null` with the checked number from the survey (N = 50).
The Results page updates automatically. `[DATA NEEDED]` marks values that have not been entered yet.

## Publishing on GitHub Pages
Upload all files to a GitHub repository → Settings → Pages → Branch: main, folder: / (root).
Or drag the unzipped folder onto https://app.netlify.com/drop
